How this simulation works

Your voice is transcribed by Gnani Prisma STT (Hindi/Hinglish). An LLM agent (OpenRouter) decides which action to take - find donors, create a request, check donation cooldown, or escalate - and deterministic code executes it against 16 synthetic demo donors with real ABO/Rh compatibility, distance and cooldown rules. The reply is spoken back by Gnani Timbre TTS. The same four tools are also exposed as an MCP server at /mcp (spec 2025-11-25, Streamable HTTP) - the standard that powers real Alexa+ integrations. No real donors, no real messages.
